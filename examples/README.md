# Examples

Open the `.html` files directly in a browser. They use the files in `../dist/`.

| Example | What it shows |
| --- | --- |
| [basic.html](basic.html) | Every item type in one panel |
| [dashboard.html](dashboard.html) | A system-monitor dashboard with live meters and alerts |
| [settings.html](settings.html) | A settings panel that saves to localStorage and re-themes itself |
| [electron-starter/](electron-starter/) | A complete minimal Electron app (`npm install`, `npm start`) |
| [light-theme.html](light-theme.html) | A light-themed control panel using CSS variable overrides |
